# RappiClone Front-End (Catálogo Full +110 Productos)

## Qué incluye esta versión
- **18 comercios** en las **8 verticales** (Restaurantes, Supermercados, Farmacia, Licores, Turbo 10m, Mascotas, Tecnología y RappiFavor).
- **112 productos** con descripción detallada, precio y botón de agregado rápido.
- **Vista previa ampliada**: cada tarjeta muestra 3 productos destacados y el botón para abrir el menú completo.
- **Modal con buscador interno**: al abrir cualquier comercio puedes filtrar sus productos al instante.
- **Carrito lateral** con control de cantidades, propina y resumen de pedido.
- **Formulario de aliados** con validación en tiempo real.

## Cómo ejecutar
1. Extrae `rappi-clone-v3.zip`.
2. Abre `index.html` en tu navegador.
